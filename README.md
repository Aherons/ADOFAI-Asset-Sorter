# ADOFAI 素材分类工具

一款面向《冰与火之舞》谱师和素材整理者的本地批量分类工具。把杂乱素材交给它，即可自动识别云、城市、山、石头、树木、发光等类型，同时拦截文字图、标题、签名、Logo 字牌和背景图。

无需手动逐张筛选，支持模型扩展，分类结果直接按文件夹输出。

## 核心功能

- **CLIP 本地识图**：结合文件名、图像内容与参考模型综合分类。
- **逐帧保护**：自动识别连续编号素材，降低序列帧被拆散的风险。
- **哈希去重**：相同图片只保留一份，避免重复输出。
- **智能过滤**：自动拦截文字、标题、签名、Logo 字牌及背景图。
- **可插拔模型包**：向对应目录添加参考图，即可扩展或强化分类能力。
- **原地重新分类**：输入与输出选择同一目录时，成品自动放入“分类结果”。
- **图形化操作**：选择文件夹、点击运行，实时查看进度和分类统计。
- **本地处理**：素材无需上传，模型下载完成后可离线使用。

## 快速上手

1. 下载并解压 **ADOFAI 素材分类工具 v1.4.5**。
2. 双击最外层的 `素材分类工具.exe`。
3. 选择素材所在文件夹和成品输出文件夹。
4. 点击“开始运行”，等待分类完成。

> 请保留 EXE 旁边的“程序文件”文件夹，不要只单独复制 EXE。

## 模型扩展

`程序文件/模型扩展/` 中可放置云、城市、山、石头、树木等参考素材，也可以创建新的类别文件夹。

v1.4.5 已移除内置 `_文字` 参考目录及文字模型学习功能，不再分发文字参考素材；旧模型包中的文字参考目录也会被自动跳过。文字及署名素材的过滤功能仍然保留。

## 版本说明

- 当前版本：**v1.4.5**
- 500MB 版首次运行需要联网下载约 580MB 的 CLIP 模型，仅需下载一次。
